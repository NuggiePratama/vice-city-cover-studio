Vice City Cover Studio turns any photo and a caption into GTA 6-style multi-panel cover art: five poster layouts, five sunset/neon grades, per-panel crop and position, bold Anton lettering with a Pacifico script subtitle, and one-click PNG export in 1080x1080, 1080x1350 and 1920x1080. Everything runs offline in the browser — photos never leave the machine.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. Add photos, pick a layout and a grade, write the caption, drag any panel to reposition its photo, and export.
